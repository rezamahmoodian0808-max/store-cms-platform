# Modern E-Commerce & Business CMS Platform
### سامانه جامع وب‌سایت کسب‌وکار و فروشگاه آنلاین با سیستم مدیریت محتوا (CMS)

A production-ready, high-performance, modular business and e-commerce CMS platform designed to scale to **100+ dynamic SEO pages**, featuring independent and modular **Product Priority Systems** and **Visual Color Swatch Systems**, complete with an administrative dashboard, bilingual/RTL support, and automated free SSL (HTTPS) configuration.

## 🛠 معماری و استک فنی (Tech Stack & Architecture)

- **Backend Web Engine**: [FastAPI](https://fastapi.tiangolo.com/) (Python 3.13) + [Uvicorn](https://www.uvicorn.org/) (ASGI). حداکثر سرعت و پایداری، عملکرد Async، مدیریت نشست‌ها (Session) و مستندات خودکار OpenAPI/Swagger در `/api/docs`.
- **Database Engine**: [SQLite](https://www.sqlite.org/) همراه با قابلیت `WAL` (Write-Ahead Logging) و پشتیبانی از کلیدهای خارجی. کاملاً پرتابل، بدون نیاز به نصب سرویس‌های سنگین خارجی، مناسب برای هزاران صفحه داینامیک و ترافیک بالا.
- **Template Engine**: [Jinja2](https://jinja.palletsprojects.com/) با معماری ماژولار و تفکیک کامپوننت‌های رابط کاربری.
- **Styling & Design System**: [Tailwind CSS](https://tailwindcss.com/) با پالت رنگی حرفه‌ای تجارت الکترونیک، چیدمان واکنش‌گرا (موبایل، تبلت و دسکتاپ)، تایپوگرافی فارسی (Vazirmatn) و انگلیسی (Inter) با پشتیبانی کامل از دو حالت RTL و LTR.
- **Interactive UI**: [Alpine.js](https://alpinejs.dev/) برای سواچ‌های رنگی زنده، تغییر آنی عکس و قیمت، سیستم انتخاب سلسله‌مراتبی اولویت‌ها، و منوی ناوبری موبایل.
- **Icons**: [Lucide Icons](https://lucide.dev/) به صورت SVG برداری با بارگذاری فوق‌سریع.
- **Security & Cryptography**: رمزنگاری کلمه‌های عبور با الگوریتم استاندارد `PBKDF2 HMAC SHA-256` (۱۰۰,۰۰۰ راند) به همراه Salt تصادفی و توکن‌های نشست امضاشده بر پایه HMAC SHA-256.

## 🎨 قابلیت‌های مدولار فروشگاهی (Modular Features)

بر اساس نیازمندی‌های مطرح شده، دو قابلیت اختصاصی با انعطاف‌پذیری ۱۰۰٪ پیاده‌سازی شده‌اند:

### الف) سیستم تعیین اولویت سفارش (Priority System)
> **الهام گرفته از رفتار سایت نوشت‌افزار معدل** (در محصولاتی مانند پنتر تراش handy ps-104)

- **کاربرد**: در کالاهایی که تنوع رنگ یا مدل دارند اما موجودی یک رنگ خاص ممکن است محدود باشد، خریدار می‌تواند **اولویت اول** و **اولویت دوم** دلخواه خود را تعیین کند تا در صورت اتمام موجودی اولویت ۱، پشتیبانی کالا را بر اساس اولویت ۲ ارسال نماید.
- **منطق هوشمند انتخاب (Mutual Exclusion)**: زمانی که کاربر گزینه‌ای را در فیلد «اولویت اول» انتخاب می‌کند، جاوااسکریپت به صورت خودکار آن گزینه را در دراپ‌دان «اولویت دوم» غیرفعال (Disabled) می‌سازد تا از انتخاب همزمان یک گزینه جلوگیری شود.
- **باکس راهنمای سفارشی**: پیام شفاف برای خریدار نمایش داده می‌شود: *«در صورت موجود نبودن رنگ‌های دلخواه شما، پشتیبانی برای هماهنگی با شما تماس خواهد گرفت.»*

### ب) سیستم پالت و سواچ رنگی (Color Swatch System)
> **الهام گرفته از رفتار سایت آریاپن** (در محصولاتی مانند ماژیک وایت‌برد پرشیا)

- **کاربرد**: نمایش سواچ‌های دایره‌ای زیبا برای انتخاب پالت رنگی با پیش‌نمایش کد رنگی (Hex) و تولتیپ نام رنگ.
- **واکنش‌گرایی زنده (Live Reactive Updates)**: با کلیک روی هر سواچ رنگ:
  - حاشیه فعال (Active Border) و آیکون چک‌مارک روی رنگ انتخاب‌شده ظاهر می‌شود.
  - نام رنگ در بالای سواچ‌ها بروزرسانی می‌گردد.
  - قیمت کالا در صورت وجود قیمت اختصاصی برای آن رنگ تغییر می‌کند.
  - کد کالا (SKU) و میزان موجودی انبار برای آن رنگ خاص بروزرسانی می‌شود.
  - تصویر بزرگ گالری به تصویر اختصاصی همان رنگ سوییچ می‌کند.

### استقلال و انعطاف‌پذیری قابلیت‌ها
این دو سیستم کاملاً مدولار و مستقل طراحی شده‌اند:
1. **یک محصول می‌تواند فقط سیستم اولویت داشته باشد** (مانند تراش فانتزی پنتر نمونه).
2. **یک محصول می‌تواند فقط سیستم واریانت رنگی داشته باشد** (مانند ماژیک وایت‌برد پرشیا نمونه).
3. **یک محصول می‌تواند از هر دو قابلیت همزمان استفاده کند** (مانند دفتر طراحی سیمی آریا نمونه).
4. **یک محصول می‌تواند هیچ‌کدام را نداشته باشد و یک کالای ساده استاندارد باشد** (مانند منگنه استیل کانگرو نمونه).
5. **کلیدهای سراسری (Master Toggles)**: در بخش تنظیمات پنل مدیریت (`/admin/settings`) دو سوییچ سراسری تعبیه شده که به مدیر اجازه می‌دهد هر یک از این دو سیستم را برای **کل سایت** در یک ثانیه فعال یا به طور کامل خاموش کند بدون اینکه در ساختار صفحات خطایی ایجاد شود.

## 📈 سیستم مدیریت محتوا و طرح گسترش به بیش از ۱۰۰ برگه

یکی از اهداف اصلی این پروژه، توانایی میزبانی و مدیریت بیش از ۱۰۰ صفحه محتوایی مجزا (صفحات سئو، مقالات، خدمات شهری و لندینگ‌ها) از طریق پنل مدیریت است.

### ساختار آدرس‌دهی و دیتابیس
- هر برگه در جدول `pages` ذخیره می‌شود و دارای `slug` یکتا است.
- روت داینامیک `/page/{slug}` از طریق یک تابع واحد، هر برگه‌ای که در دیتابیس ساخته شود را در کسری از میلی‌ثانیه واکشی نموده و با متاتگ‌های سئو (`meta_title` و `meta_description`) رندر می‌کند.

### ابزار تولید انبوه صفحات (Bulk Page Generator)
برای اثبات و فعال‌سازی این قابلیت در عمل:
1. در پنل مدیریت به بخش **برگه‌ها (`/admin/pages`)** مراجعه کنید.
2. بر روی دکمه سبز رنگ **«تولید خودکار ۲۵ برگه سئو»** کلیک کنید.
3. سیستم به طور خودکار ۲۵ برگه سئو با محتوای اختصاصی برای شهرهای مختلف ایران (مانند *خرید عمده نوشت‌افزار در شیراز*، *تامین لوازم تحریر در اصفهان* و...) ایجاد می‌کند.
4. با چند کلیک می‌توانید سایت را از ۲۰ صفحه به ۱۰۰ یا ۲۰۰ صفحه گسترش دهید.

## 🚀 راهنمای راه‌اندازی سریع (Quickstart Guide)

### ۱. پیش‌نیازها
- پایتون نسخه 3.10 به بالا (تست‌شده روی Python 3.13)
- مدیر بسته `pip`

### ۲. نصب وابستگی‌ها
در پوشه پروژه دستور زیر را در ترمینال یا PowerShell اجرا کنید:
```bash
pip install -r requirements.txt
```

### ۳. مقداردهی اولیه پایگاه داده (Seed Data)
برای ایجاد جداول و بارگذاری محصولات نمونه، مقالات وبلاگ، دسته‌بندی‌ها و حساب‌های مدیر، دستور زیر را اجرا کنید:
```bash
python seed.py
```

### ۴. اجرای برنامه
تنها با اجرای یک دستور، سرور با حالت Hot-Reload بالا می‌آید:
```bash
python run.py
```
یا با دستور مستقیم Uvicorn:
```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### ۵. نشانی‌ها و دسترسی پیش‌فرض
- **فروشگاه و ویترین سایت**: `http://localhost:8000`
- **کاتالوگ محصولات**: `http://localhost:8000/catalog`
- **وبلاگ آموزشی**: `http://localhost:8000/blog`
- **پنل مدیریت CMS**: `http://localhost:8000/admin`
  - **ایمیل مدیر**: `admin@example.com`
  - **رمز عبور**: `admin123456`
  - **حساب کاربری محرر (Editor)**: `editor@example.com` / `editor123456`
- **مستندات تعاملی Swagger API**: `http://localhost:8000/docs`

## 🔒 تنظیمات SSL رایگان و استقرار در محیط پروداکشن

سایت به طور کامل آماده پروتکل HTTPS است:
- تمامی لینک‌ها، تصاویر و استایل‌ها از آدرس‌دهی نسبی یا HTTPS استفاده می‌کنند.
- میان‌افزار امنیتی در `app/main.py` هدرهای امنیتی `HSTS (Strict-Transport-Security)`، `X-Frame-Options` و `X-Content-Type-Options` را به تمام پاسخ‌ها اضافه می‌کند.
- با تنظیم `FORCE_HTTPS=true` در فایل `.env`، تمامی درخواست‌های ناامن HTTP به طور خودکار به HTTPS هدایت (301 Redirect) می‌شوند.

### روش ۱: استفاده از Caddy (ساده‌ترین روش با SSL خودکار Let's Encrypt)
[Caddy Server](https://caddyserver.com/) به صورت کاملاً خودکار و بدون نیاز به هیچ اسکریپتی، گواهی SSL رایگان Let's Encrypt را از طریق پروتکل ACME صادر و تمدید می‌کند:
1. فایل آماده `Caddyfile` در ریشه پروژه قرار دارد.
2. دامنه خود را در `Caddyfile` به جای `yourdomain.com` قرار دهید.
3. دستور زیر را روی سرور اجرا کنید:
   ```bash
   caddy run --config Caddyfile
   ```
گواهی SSL ظرف چند ثانیه دریافت و پروتکل HTTPS فعال می‌شود!

### روش ۲: استفاده از Nginx و Certbot روی اوبونتو/دبیان
فایل پیکربندی بهینه‌شده `nginx.conf` در پروژه قرار دارد:
```bash
# ۱. کپی کانفیگ به دایرکتوری Nginx
sudo cp nginx.conf /etc/nginx/sites-available/stationery
sudo ln -s /etc/nginx/sites-available/stationery /etc/nginx/sites-enabled/

# ۲. دریافت رایگان گواهی SSL از Let's Encrypt با دستور تک‌خطی Certbot
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```
سرتیفیکیت‌ها به صورت مادام‌العمر و خودکار هر ۶۰ روز توسط Certbot تمدید خواهند شد.

### روش ۳: استفاده از کلودفلر (Cloudflare Universal SSL)
اگر دامنه شما روی Cloudflare ست شده باشد:
1. قابلیت **Proxy Status** را برای رکوردهای A روشن کنید (آیکون ابر نارنجی).
2. در منوی **SSL/TLS** کلودفلر، حالت **Full** یا **Full (Strict)** را برگزینید.
3. وب‌سایت بدون نیاز به نصب هیچ ابزاری دارای نماد قفل سبز و گواهی رایگان SSL خواهد شد.

### روش ۴: استقرار با Docker و Docker Compose
فایل‌های `Dockerfile` و `docker-compose.yml` در پروژه قرار داده شده‌اند:
```bash
docker compose up -d --build
```
این دستور کل برنامه را به همراه سرور پروکسی Caddy در حالت ایزوله و پروداکشن با SSL فعال بالا می‌آورد.

## 📡 مستندات API هدلس (Headless REST API)

این سامانه به عنوان یک Headless CMS نیز کار می‌کند و می‌توانید فرانت‌اندهای جداگانه (React، Next.js، اپلیکیشن موبایل Flutter یا React Native) را به آن متصل نمایید:

| متد | مسیر (Endpoint) | توضیحات |
| :--- | :--- | :--- |
| `GET` | `/api/products` | لیست محصولات با فیلتر دسته‌بندی و جستجو |
| `GET` | `/api/products/{slug}` | مشخصات تکی محصول شامل سواچ‌های رنگ و گزینه‌های اولویت |
| `GET` | `/api/pages` | لیست تمامی برگه‌های داینامیک CMS (پشتیبانی از +۱۰۰ برگه) |
| `GET` | `/api/pages/{slug}` | محتوای کامل یک برگه به همراه متاتگ‌های سئو |
| `GET` | `/api/blog` | لیست مقالات وبلاگ با فیلتر موضوعی |
| `GET` | `/api/settings` | تنظیمات اصلی برند، شماره‌های تماس و وضعیت کلیدهای سراسری |
| `GET` | `/docs` | رابط کاربری تست تعاملی OpenAPI / Swagger |

## 🛡 پشتیبانی و سفارشی‌سازی
کدهای این پروژه با بالاترین استانداردهای کدنویسی تمیز، ساختار ماژولار و تفکیک لایه‌های Controller/Model/View توسعه یافته‌اند و به راحتی با درگاه‌های پرداخت، پیامک‌های اطلاع‌رسانی و سامانه‌های انبارداری قابل اتصال می‌باشند.
